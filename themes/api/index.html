GET/meta.json

读取站点元数据

获取静态接口的类型与能力说明。live_monitoring: false 表示没有配置实时监测，不能把这个响应当作其他服务健康检查。

响应字段

schema_versionstring

这份静态文档使用的结构版本。

servicestring

资源所属的服务类型。

live_monitoringboolean

是否接入实时监测；当前为 false。

在浏览器中查看真实响应 ↗

检查响应头

只获取资源的响应头，不下载响应体。文件内容发布更新后，缓存相关头部会随实际服务器行为变化，本站不伪造固定的过期时间。

Request examplecURL
curl --head https://{{DOMAIN}}/meta.json

实际头部以服务器返回为准。

LIMITS

错误与限制

200
文件读取成功

有效路径返回对应的静态资源。

404
资源不存在

不存在的路径使用正常的 HTTP 404。

403
写入不被允许

默认静态站不接受 POST 等写入方法；错误页不承诺是 JSON。

此说明针对 ToastWeb 默认站点配置。模板本身不启动应用服务，也不改变证书、DNS 或其他服务配置。
