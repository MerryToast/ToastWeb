INTRODUCTION

构建清晰、可维护的静态文档站点

{{SITE_DESCRIPTION}}

这份手册记录了站点内容的组织结构、本地构建与发布校验流程，以及日常维护时的安全与隐私边界。通过将文档收敛为纯静态 HTML、CSS 与矢量资源，站点可以在保持高速响应的同时，彻底消除对数据库、动态运行时及第三方脚本的依赖。

关于这份文档手册

当前页面是站点的标准文档基线。你可以根据实际项目需求替换正文或发布使用文档生成工具构建的静态目录，始终保持公开内容与实际功能一致。

01 / QUICKSTART

三步完成内容准备与上线

良好的文档站点不需要复杂的后台系统。围绕“编写—预览—原子发布”三个环节，即可建立稳定可靠的内容更新节奏。

STEP 01 Authoring

梳理章节与导航

编写结构清晰的文档正文，确保每个章节标题拥有固定锚点，所有内部链接与资源引用均采用相对路径。

STEP 02 Verification

多视口本地预览

在桌面宽屏与移动端窄屏下分别核对排版、表格与代码区域，确认不存在横向溢出或失效的静态资源。

STEP 03 Release

版本化发布与核验

将构建产物发布为独立版本目录并切换当前指针，保留上一版本快照以便在发现版面问题时随时回退。

02 / DIRECTORY STRUCTURE

保持直观的静态目录结构

无论是手工维护 HTML 还是使用静态站点生成器（如 Hugo、VitePress 等）在本地预构建，最终发布的产物都应当是一个自包含的纯静态目录。

public/ — 静态发布目录结构示例 STATIC FILES 
public/
├── index.html                # 站点入口文档，包含完整语义化章节与导航
├── guides/
│   ├── getting-started.html  # 可选的专题子页面（使用相对路径互链）
│   └── maintenance.html      # 运维与排障核对清单
└── assets/
    ├── theme.css             # 本地样式表（不含远程 @import 或外部字体）
    └── mark.svg              # 站点矢量图标与内联图形资源

提示：公开站点目录中不应包含隐藏文件（如 .env、.git）、符号链接或任何私钥凭据。示例目录仅用于说明组织方式。

03 / SPECIFICATIONS

静态资源与交付标准

为了保证文档在各类网络环境与浏览器中均能稳定、安全地呈现，本站遵循以下静态资源与 HTTP 交付规范：

模块维度 采用标准 设计约束与安全边界
文档标记 HTML5 Semantic 仅包含静态排版与折叠标签，不含表单、输入框、脚本或内嵌框架
样式与字体 System UI Stack 优先调用操作系统原生中英文字体栈，不请求第三方远程字体服务
请求方法 GET / HEAD 仅响应只读访问请求，拒绝 POST、PUT 等写入方法
响应安全头 nosniff & Referrer 默认启用内容类型嗅探保护与严格的跨源引荐来源策略
04 / PUBLISH & ROLLBACK

可验证的发布与回退工作流

每次内容更新都应当是可逆的。在将新构建的静态文件推送上线前，请按照以下核对清单完成上线前自检与上线后验证：

PRE-FLIGHT 发布前核对要点
  • 确认根目录包含有效的 index.html 入口文件
  • 清理构建目录中的临时草稿、隐藏文件与构建缓存
  • 核对所有页内锚点与静态资源路径均可正常解析
POST-RELEASE 上线后与回退处置
  • 通过 HTTPS 访问首页与静态资源，检查状态码与排版
  • 若发现内容错误或样式异常，立即切回上一版本目录
  • 保留最近若干个已验证的历史版本以备比对审计

05 / MAINTENANCE PRINCIPLES

把注意力留给真正有用的内容

一个耐用的文档网站依靠克制的设计而非堆砌功能来维持长期可靠。日常维护中建议坚持四项基本准则：

  • 坚持本地自包含资源： 页面所需的样式与图形全部保存在本地目录，不引入广告、追踪器或外部 CDN 脚本。
  • 坚持真实准确的信息表达： 未接入实时探测时不展示虚构的在线率，未提供动态后端时不放置无效的搜索框或登录入口。
  • 坚持有边界的公开范围： 公开文档只记录面向读者的使用说明，绝不将内部管理口令、私钥或非公开拓扑写入页面。
  • 坚持定期巡检与备份： 定期核查 TLS 证书有效期、链接可达性以及历史版本备份的完整性。
06 / FREQUENTLY ASKED QUESTIONS

常见问题解答

浏览这个文档站点需要注册账号或登录吗？

不需要。本站为纯静态只读文档站点，不提供用户系统或登录接口，也不会收集、存储访客的任何输入信息。

可以使用静态站点生成器生成的目录替换当前内容吗？

完全可以。在本地或 CI 环境完成静态构建后，只需将包含 index.html 及静态资源的输出目录发布上线即可。

为什么页面中不使用外部网络字体或第三方统计组件？

移除第三方资源可以消除跨站请求带来的隐私顾虑与加载阻塞，即使在受限网络环境下也能瞬间完成渲染。

页面底部显示的时间代表什么含义？

代表当前静态文档版本的生成与发布时间（UTC），用于帮助读者确认当前查阅的内容版本，而非实时动态计数器。
